3.22

Composition is a contract now: every component declares where it attaches, what it conflicts with, and the engine is tested against its own declaration.

2026-07-19
  • With 20+ drawable components (collars, plackets, peplums, pockets, slits, gathers...), the real cost is not each component but their interactions: they grow as n squared and used to live as scattered if-statements and hand-managed drawing rules. Every component now has a declared attachment point, a z-order (the exact order the engine applies them) and a conflict class, in one data file (contract/composition.json), with a full conflict matrix: 74 host rules + 58 pair rules across five honest classes (drawn clean, refused with a named error, blocked by the validator, skipped with a spoken note, or ignored by documented design).
  • The matrix is not documentation, it is tested. A new permanent test (compose_check) drafts 248 host-component singles and 465 component pairs through the real engine on every run, derives the observed class of each and fails on any mismatch with the declaration, in either direction. A silent no-op that is not explicitly declared is a test failure by definition.
  • Writing the matrix surfaced 20 places where the engine used to swallow a field silently: ask for a peplum on a skirt, or a walking vent on a gathered skirt, and nothing was drawn and nothing was said. Those combinations now refuse with a sentence that names the field (the web pickers already prevented all of them, so only raw API callers ever see it). The published numbers did not move by design or by accident: the 0-call benchmark re-measure reads exactly the same 27 of 54 full, 74 of 103 elements, 94.4% vision accuracy as before.
  • The flat drawing engine had zero tests (a known audit finding). It now has a render lint that draws every stored style headlessly and checks for self-intersecting outlines, reversed winding, zero-area loops and a geometry property the shirring code silently relies on (y-monotone silhouette segments). It runs in the test suite and is chained into the existing pre-deploy lint, so it cannot be forgotten.
composition contract + 2 new permanent tests · engine byte-identical on every coherent spec · 20 silent no-ops now refuse honestly · full patterns 27 of 54 unchanged, re-proven at 0 cost

Declaring the current behavior also meant declaring its warts, and they are published, not fixed: an off-shoulder band on a top drafts into a validator block today, a tie on a skirt disturbs its waistband math, a keyhole fights every other center-front component (the validator catches all of these and withholds the PDF), and two flat styles carry small cosmetic self-intersections that are now pinned so they can never silently multiply. The matrix froze the truth; repairs are the next version's work.
