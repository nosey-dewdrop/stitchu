3.2

The tiled pattern joins up on paper, with fewer pages.

2026-07-17
  • A machine check now proves the register system lines up across pages. It drafts a multi-page pattern, reads every corner square, edge tick and page code, and confirms each mark on a shared edge lands on the exact same point as its partner on the next sheet, to within a hundredth of a millimetre. Across 141 neighbouring page pairs, every mark met its partner: taped together, the squares complete and the ticks meet.
  • A long, thin piece can now lie on its side so it stops eating rows of near-empty pages. The outline is never redrawn, only turned, and the check confirms every point keeps its exact distances, so the shape is identical. A wide gathered panel that used to run silently off the edge of the strip is now caught and given the room it needs. Across the test set the page count dropped from 462 to 437 with no pattern getting worse.
  • The cover now carries a numbered cutting list: every piece has a number, its cut instruction, and the exact sheets it prints on. A piece split over four pages is found at a glance instead of hunted for.
register continuity proven across 141 page pairs · pages 462 to 437 · zero pattern regressions

No pattern accuracy number moves here; this is the print output layer, not the drafting engine. What it fixes is real: the pieces already lined up, but there was no proof and too many pages made a correct pattern feel like it would never join. The rotation is a rigid turn, verified point by point, so a piece can never be reshaped by being packed. The final proof is a printed dress, so the note for the next step is: print Jackie again and tape it.
