Two root causes were fixed in the pen: puff was read only off the numeric `sleeveCap === 2` field and never off the sleeve's own name, and raglan was the condition of no branch at all. Where the pattern engine cannot cut what was asked for, the flat now stamps the missing operator's name into `data-engine-gap` on the SVG root instead of drawing something else quietly.
docs/ARCHITECTURE.md:121:**A comparison board was built, and its first honest result was that this phase changed nothing visible in it.** `engine/tools/flat-board.mjs` renders one row per style, ESKİ on the left and YENİ on the right, embedding each SVG with `xMidYMid meet` and `overflow="visible"` — scaled, never cropped, never retouched. `--eski <dir>` reads the left column *off disk* and aborts loudly if a file is missing. That flag exists because the board's first version only had `--yeni`, which filled the right column and regenerated the left one from today — an "ESKİ|YENİ" board that would have shown today in both columns (`GECE/V4-D.md`, KART DIŞI 3). Where no old artefact existed at all, as with the sleeve family, the old commit was checked out into a detached worktree and the pen was run there, and the resulting hashes were matched against the ones already recorded in the gate's header before the column was trusted.
