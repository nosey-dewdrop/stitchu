## 1. Flat kalıptan mı türüyor?

**HAYIR. Flat, kalıbın geometrisine HİÇ dokunmuyor; ayrı parametrik şablondan
çiziliyor.** Kaynağın kendisi bunu yazıyor, ve imza da bunu doğruluyor:

- `engine/tools/render-garment-flat.mjs:11-14` —
  "So this renderer draws the flat PARAMETRICALLY FROM THE STYLE SPEC, never from
  the pieces. It reads neckline / sleeveStyle / sleeveLength / sleeveCap / shaping
  / skirtStyle / topLength / collar / placket / tie / gather / backOpening / closure
  and draws a clean finished-garment FRONT and BACK."
- `engine/tools/render-garment-flat.mjs:23-24` —
  "Exports renderGarmentFlat(pieces, spec). `pieces` is accepted for signature
  compatibility but NOT used to derive the outline — the flat is spec-driven."
- `engine/tools/render-garment-flat.mjs:829` — "`pieces` is unused for the outline
  (kept for signature compatibility)."

Yorum değil, ölçüm: `grep -n "pieces" engine/tools/render-garment-flat.mjs` 861
satırlık dosyada 7 satır döndürüyor ve **hiçbiri gövde değil** — 4'ü yorum
(12/23/242/829), 3'ü imza/aktarım (833 `renderGarmentFlatAsync(pieces, spec)`,
836 `renderGarmentFlat(pieces, spec)`, 839 `export function renderGarmentFlat(pieces, spec = {})`).
`pieces` parametresi fonksiyon gövdesinde **0 kez okunuyor**. Çizimi üreten iki
çağrı (`render-garment-flat.mjs:840-841`) sadece `spec` alıyor:
`const fp = viewPanel(spec, 'front'); const bp = viewPanel(spec, 'back');`

İkinci yol da spec-güdümlü, kalıp-güdümlü değil:
`render-garment-flat.mjs:726-826` `tryReferencePen(spec)` — spec'i bir stil
ANAHTARINA (`styleKey`) eşliyor (`:749-805`), sonra
`:822 return ref.renderStyle(styleKey, overrides)` ile
`engine/flat-engine/_engine-full.mjs`'i çağırıyor. Girdi yine spec + 15 kadran
(`:811` size/length/skirtFull/ink/foldCount/hemWave/drape/hemDip/seed/
bustProject/bustHeight/waistNip). Kalıp parçası, dikiş grafiği, panel konturu
bu yola da girmiyor.

Yani flat ile kalıp arasında **paylaşılan tek şey spec sözcükleri**; paylaşılan
geometri YOK.
