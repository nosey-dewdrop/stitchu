3.4

A tighter A4 packer, so the same pattern prints on fewer pages.

2026-07-17
  • The old layout laid pieces out in shelves, like books on a bookcase: a short piece on a tall shelf wasted the whole height above it. A new skyline packer drops each piece into the lowest free gap instead, so a small piece tucks into the space beside or above a larger one. Both packers now race for every pattern and the one that prints fewer pages wins, so the layout can only ever get tighter, never worse.
  • The packer also tries several placement orders and lets each piece turn 90 degrees at packing time if it tucks lower, still a rigid turn that never reshapes the outline. On a fixed set of 22 real photo-to-pattern drafts the total page count dropped from 456 to 430, with not one pattern getting worse. Jackie alone went from 17 pages to 16.
  • Every layout was re-checked point by point: no two pieces overlap, none runs off the strip, the gap between pieces stays exactly right, and every turned piece keeps its exact distances. The register system still lines up across pages within a hundredth of a millimetre, so the pattern still tapes together perfectly, just on fewer sheets.
pages 456 to 430 on the 22-draft test set · zero pattern regressions · register continuity re-proven

No pattern accuracy number moves here; this is the print output layer, not the drafting engine, and the true scale is never touched. A minus 26 page saving is real but the returns are now small: the last few strategies each saved only a page or two, so this line of work is parked here until the sheet count clearly hurts again. The final judge is still a printed, taped dress.
