3.28

A bug fix, not a new garment: an asymmetric-placket top used to report a false side-seam mismatch. The geometry was always correct and sewable; the validator was measuring the wrong edge.

2026-07-23
  • An asymmetric front placket on a top made the validator flag a side-seam mismatch, front 324.9 against back 356.4 mm, and refuse the draft. The pattern was never wrong: on a grown-on centre-front edge the side-seam locator was reading the wrong edge, so it compared two lengths that were never meant to match. The locator was fixed to find the true side seam.
  • Because only the validator's measuring point moved and no drafted point changed, the golden reference is unchanged. An asymmetric-placket top now drafts with 0 issues and is wearable. This is the honest kind of fix: the engine was already right, the checker was wrong, and now the checker agrees.
