3.7

The engine now drafts an asymmetric placket and a cap sleeve.

2026-07-17
  • An asymmetric placket carries the row of buttons off to one side instead of straight down the middle. The engine already drew a centered button stand; it now shifts the whole closure, the fold line, the buttons and the buttonholes, off center, grows the front edge to match, and still marks the true center front as a reference line so you can see how far over it sits. It is the classic sixties shift-dress front.
  • A cap sleeve is a short wing that covers the top of the shoulder and dies away at the underarm, with no seam to sew shut. The engine now drafts it: it keeps the ordinary set-in cap so the wing eases into the armhole exactly like a full sleeve, then cuts the sleeve off just below, so a little curved wing is all that is left. You finish its outer edge and set it into the armhole.
full patterns 31 of 54 to 37 of 54 · all six Jackie gingham photos now complete

These two pieces had to ship together: the Jackie gingham photos want both an off-center placket and a cap sleeve, so drawing one alone completed almost none of them, and drawing both completed all six. Only the plain button-stand cap sleeve is drawn; a pleated or draped variant, and a back or double-breasted asymmetric closure, still stay honest. The base draft is byte-identical with both off, so no existing pattern changed: 22 engine tests pass, 20190 web drafts and 37800 vocabulary drafts pass with zero failures, and the golden reference is unchanged to the millionth of a millimetre.
