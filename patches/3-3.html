3.3

A couture showcase, to see how far the features stack.

2026-07-17
  • Most patterns on the site are quiet, safe garments. A new showcase page does the opposite: four couture looks, each stacking the engine's full opt-in vocabulary onto one dress. Nuit Étoilée is a low-V open-back gown with puff sleeves, a waist bow and a walking vent. Halter Coquette is a bias-bound halter with a three-tier ruffle cascade. Mademoiselle is a stand-collar shirt-dress with a grown-on button front. The fourth stacks every drawable feature at once as a stress test.
  • Every pattern piece on the page is the engine's own output at an EU38 body, drafted through the same engine the create page runs, not a rendering or a sketch. Across the four looks that is 52 pieces, and the validator returned no issue in that run on all four. The stress-test gown alone stacks seven opt-in blocks (sweetheart, puff sleeve, keyhole, open back, bow, vent, ruffle) into 17 pieces without one complaint, which is the real finding: the drafting layers compose freely because each only adds its own pieces and never touches the outlines the others drew.
4 couture looks · 52 pattern pieces · 0 validator issues

The full-pattern number does not move here; a showcase draws with features that already shipped, it does not add new ones. What it proves is composition, not capability. It also found no engine limit: not one couture combination had to be dropped or fell back to a tamer alternative. When the engine one day cannot draw a requested stack, that gap gets published here too.
