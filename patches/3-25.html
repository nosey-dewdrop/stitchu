3.25

One deploy command now ships the site: the cache version is bumped on every page automatically, the whole proof chain gates the ship, and a class of human error dies. Plus an archive sweep and an operational privacy scan.

2026-07-19
  • Deploys used to be a hand-run ritual: bump the cache version in every file, remember every check, split the web tree, force-push, verify live. At one point eight different versions were live at once, and a stale page once shipped to real visitors. The new script computes the next version, applies it to every page, refuses to ship if more than one version exists, runs the style lint, the render lint, the preview-truth check, the header consistency proof, the contract validation and the full 45-test engine suite, and only then pushes and verifies the live site with a cache-busting fetch.
  • If undeployed work touches the drafting engine itself, the script stops and demands the full motor proof set (both WebAssembly builds, the golden byte-identity diff, the sweep and fuzz runs) before it will ship anything. Silent stale-engine deploys join the dead bug classes.
  • An operational privacy scan walked every token and identifier: the benchmark bypass token has never entered git history, the API keys live only as Cloudflare secrets, the photo corpus and purchased patterns stay local and ignored, and the term-synonym map behind the published 6.7% corpus number carries no photo names or sources, so it is now committed and the number is reproducible by anyone.
  • The attic got cleaned: eleven one-off proof scripts and their outputs, seven design mockups, the asset guides and two orphaned renderer experiments moved to the archive, and an old unimplemented vocabulary spec now carries an explicit unverified-and-parked stamp so nothing mistakes a draft for a plan. Six em dashes that had crept into this very page were removed; the style lint that forbids them gates every future deploy.
benchmark unchanged: 27 of 54 full patterns, element accuracy 74 of 103 · one deploy command, proof-gated, version drift impossible · privacy scan clean, no secret ever committed · 20+ files archived

Two honest limits stay on the record. The worker URL is still written in three web files rather than one; instead of a risky refactor in a closing chain, the deploy gate now fails if the copies ever diverge from the single config source. And benchmark result snapshots still overwrite by date, which once already made a published number impossible to rebuild; a timestamped history is deferred to v1.1 rather than smuggled into a freeze.
