3.16The engine now drafts a cowl and a pussy-bow neckline.2026-07-17
  • A cowl neckline is a soft, draped front where the fabric falls into loose folds across the chest. The engine now draws it: it cuts the front wide and deep and marks it to be cut on the bias, so the extra fabric drapes into folds and the neck edge folds back on itself with no separate facing. It is a shape, not an extra piece; nothing about the rest of the pattern moves.
  • A pussy-bow neckline is a high neck band with a long tie that knots into a soft bow at the throat. The engine now draws two extra pieces: a stand band whose bottom edge is drafted to the exact length of the neckline, so it sews on with no easing, and a long self-lined tie strip cut to twice the neck girth, so each end reaches around and hangs long enough to tie. One tie sews into each front end of the band, then you knot them.
two new necklines · the seven originals unchanged to the millionth of a millimetre

This adds vocabulary, not accuracy on this set: none of the fifty-four test photos is a cowl, and the pussy-bow's bow was already drawn as an applied tie, so the pattern count stays at 37 of 54, honestly. The band's bottom edge is measured off the finished pieces and matches the neckline to zero, the tie length comes off the neck measurement, and both necklines are opt-in, so the base draft is byte-identical: 23 engine tests pass (a new neckline test proves the cowl is deeper and cut on the bias, the pussy-bow band matches the neckline exactly, and the seven original necklines draw no band or tie), 25730 web drafts and 48600 vocabulary drafts pass with zero failures, and the golden reference is unchanged. Verified by rendering a cowl dress and a pussy-bow blouse and reading the printed pieces by eye. An asymmetric or multi-layer draped cowl, and an asymmetric bow, still stay honest.

3.9Every pattern now passes a wearability test.2026-07-17
  • An outside AI read one of my patterns and found it could not be worn: it was drawn to button up the front, but the front had been saved as a single piece on the fold, so nothing opened and no head could fit through the neck. Every one of my tests was green, because they all checked that the pattern was internally consistent, not that a person could actually put it on. So I turned that lesson into a permanent test. The engine now checks, on every draft, that a closed-neck garment with no zipper or opening is not sealed shut, that a declared front opening did not collapse back into a plain fold, and that a sleeveless armhole is finished. These run in C++, for free, on every pattern; the AI was the teacher, the deterministic test is the defence.
new wearability gate · three blocking checks · zero false positives across 60000+ drafts

This does not move the accuracy number; it is a safety layer, not a new capability. Run against the 54 benchmark specs, zero currently draft into an unwearable pattern, so the gate is a permanent guardrail rather than a one-time fix, it will catch the failure the moment it ever recurs. It is calibrated to real tailoring tolerances so it never wrongly blocks a good pattern: it passed the full 2805-draft engine matrix, 37800 vocabulary drafts and 20110 web drafts with zero false alarms, and the golden reference is byte-identical because the checks only read the geometry, they never change it.

3.8Another AI measured my pattern and found a real bug. I fixed it.2026-07-17
  • An independent language model measured one of the engine's A4 patterns, a sleeveless boat-neck button blouse, as vectors and caught a genuine mistake: the front was drawn with a button placket AND cut on the fold at the same time. You cannot sew buttons onto a fold, so that piece could never open and never go over the head. It was unwearable. A placket opens the garment at the center front, and cutting on the fold closes it, the two decisions contradicted each other and the engine let both through. It is fixed now: whenever the engine draws a front placket, the front becomes two mirror fronts that open at the center, its neck facing follows, and the button stand grows correctly past the center front on every front shape, not just some. The boat neckline was also too narrow, reading like a wide round neck; it now opens wide and shallow toward the shoulders the way a real bateau does. And a sleeveless garment now counts the bias binding that finishes its armholes.
placket fronts now wearable · boat neck opens 226 mm wide · armhole finish counted

This is a correctness fix, not a new feature, so the full-pattern count stays 37 of 54, the placket was already counted as drawn, it was simply drawn wrong. The golden reference moved for a reason and every changed line was checked: only boat-neck drafts changed (the wider neckline) and only sleeveless drafts' fabric estimate changed (the added armhole binding), nothing else moved by a hair. Engine tests, web drafts and 37800 vocabulary drafts all pass. Two other things the audit flagged did not reproduce: the pattern pieces already carry grainline arrows, and the woven bust ease is already about 10 cm, in range. Those are reported honestly rather than 'fixed' for show.

3.5The engine now drafts a peplum.2026-07-17

3.4A tighter A4 packer, so the same pattern prints on fewer pages.2026-07-17
  • The old layout laid pieces out in shelves, like books on a bookcase: a short piece on a tall shelf wasted the whole height above it. A new skyline packer drops each piece into the lowest free gap instead, so a small piece tucks into the space beside or above a larger one. Both packers now race for every pattern and the one that prints fewer pages wins, so the layout can only ever get tighter, never worse.
  • The packer also tries several placement orders and lets each piece turn 90 degrees at packing time if it tucks lower, still a rigid turn that never reshapes the outline. On a fixed set of 22 real photo-to-pattern drafts the total page count dropped from 456 to 430, with not one pattern getting worse. Jackie alone went from 17 pages to 16.
  • Every layout was re-checked point by point: no two pieces overlap, none runs off the strip, the gap between pieces stays exactly right, and every turned piece keeps its exact distances. The register system still lines up across pages within a hundredth of a millimetre, so the pattern still tapes together perfectly, just on fewer sheets.
pages 456 to 430 on the 22-draft test set · zero pattern regressions · register continuity re-proven

No pattern accuracy number moves here; this is the print output layer, not the drafting engine, and the true scale is never touched. A minus 26 page saving is real but the returns are now small: the last few strategies each saved only a page or two, so this line of work is parked here until the sheet count clearly hurts again. The final judge is still a printed, taped dress.

3.1The engine now drafts ruffled shoulder straps.2026-07-17
  • A babydoll or camisole often hangs from a ruffled shoulder strap: a strip of fabric cut longer than the strap, then gathered along its length so it frills. The engine now drafts that strip as its own cut piece, a pair, with the fold line, the gather line and a placement notch marked at each shoulder on the front and back. Sew the tube, gather it down to the strap length, and stitch each end where the notch tells you.
  • The cut length carries the fullness: the strip is drafted at the strap span times the gather ratio, so once it is gathered back down it returns to the exact strap length, measured to a hundredth of a millimetre. Only the ruffled strap is drawn. A plain or spaghetti strap, a one-shoulder or off-shoulder band, a halter frame are different constructions and stay in the honest missing list; a sleeved or halter garment carries no separate strap, so the engine skips it and says so.
