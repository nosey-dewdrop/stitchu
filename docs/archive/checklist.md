## COLOR PALETTE

Use these colors from the mock:
- Background: #F5FAFF
- Card: #FFFFFF
- Text: #2C3E50
- Text secondary: #7B8FA3
- Baby blue (accent): #6FB3DE
- Baby blue light: #DCEEFA
- Pink light: #FFF0F1
- Sage light: #EDF3E8
- Lavender light: #F0EAF5
- Sky light: #E8F0F5

## NOTES

- All doodles should feel hand-drawn, slightly imperfect, soft
- Lines should be slightly wobbly, not perfectly straight
- Use the baby blue (#6FB3DE) for highlights and accents
- Dashed/stitched borders feel like sewing — use them
- PNG transparent background for all icons and illustrations
- Body silhouette: friendly, proportional, NOT clinical/medical
